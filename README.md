# EduMobile — Mobile-first Education UI

This is a small static demo of a mobile education app UI. It includes a landing area, lesson cards, a simple quiz modal (CSS :target demo), and a bottom navigation bar.

Files:
- `index.html` — main demo page
- `styles.css` — mobile-first CSS

How to preview:
1. Open `index.html` in your browser (double-click or use Live Server).

Notes & next steps:
- Replace the :target modal with JS-based routing for production.
- Add real lesson content, images, and icons (SVGs) for better performance.
- Convert to React/Vue for dynamic state and persistence.
